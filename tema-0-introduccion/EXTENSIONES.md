***EXTENSIONES ÚTILES PARA VISUAL STUDIO CODE***

---

**JavaScript**

- Java Script Lite Formatter

- Babel JavaScript
    * Esta segunda extension lo que no dará será notificaciones o visualizaciones de errores en nuestro codigo de JavaScript.

---
**TypeScript**

- JavaScript and TypeScript Nightl
    * Esta nos serviora tanto para TypeScript como para JavaScript.

- Pretty TypeScript Errors
    * Esta hará que los errores en TypeScrip se vean mejor.
  
---

**React Y React Native**






- React Native Tools
    * Añade funciones y utilidades básicas para la escritura de código para *React Native Tools*

- Simple React Snippets
    * Esta última lo que hará es hacer que con pocas letras podamos autocompletar lineas enteras de codico como imports y funciones.

- ES7+ React/Redux/React-Native 
    * Permite configurar lenguajes compatibles y añade aun más *snippets*

- Expo Tools
    * Añade sugerencias al codigo. También muestra *previous* de nuestras *builds* dentro de visual

---

**Unity** (En el caso de que lleguemos a trabajar en paralelo con visual studio)

- Unity
    * Permite tener un entorno ligero en C# para desarrollar con unity en visual studio code. Permite trabajar con los siguiente formatos *(.asmdef, .shader, .uss, .uxml)*.

- Unity Code Snippets
    * Al igual que *Simple React Snippets* permite tener *Shortcuts* para completar lineas.
